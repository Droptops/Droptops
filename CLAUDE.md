## Repository purpose

This is the GitHub **profile README** repository for the `Droptops` account (the repo name matches the username, so `README.md` renders on the user's GitHub profile page at https://github.com/Droptops).

It is not a software project — there is no build system, no source code, no tests, and no dependencies. The repository contains a single `README.md` and nothing else.

## What "changes" mean here

Edits are almost always content updates to `README.md`: refining bio copy, updating the project list, fixing links, or tweaking the contact section. There is nothing to compile, lint, or run.

When editing:
- Preserve the existing structure (top-level name heading, then `###` sections for "What I'm working on", "Background", "Contact").
- GitHub renders this file with GitHub-Flavored Markdown; preview links and formatting accordingly.
- External project links (e.g. `cca-prep`) point to other repos under the same owner — keep them working when renaming sections.
